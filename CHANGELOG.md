# Changelog

## 1.0.1

- The README and AGENTS.md use the download names as GitHub shows them:
  Creative.Connection.Setup.exe and Creative.Connection.zip.

## 1.0.0

- One window with a power button per device. Every .ps1 file in Turn on becomes a button.
- A log with filters and copy buttons, readable by people and AI agents.
- Help with 16 topics, an example script and a practice device.
- Install with Creative Connection Setup.exe, for you only and without admin rights,
  or start Creative Connection.exe from the zip.
- Both .exe files are built from the code in Development\bouwen, and bouw.ps1 -Check
  shows that they match it byte for byte.
