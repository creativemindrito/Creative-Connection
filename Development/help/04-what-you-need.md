# What you need

1. A Windows PC that is on. The app and your AI agent run the scripts from this PC.
2. PowerShell, which is already part of Windows.
3. A device connected to the same home network as the PC.
4. A device in rest mode or network standby, not fully off. A device that is fully off can't hear anything.
5. Your router password, for giving the device a fixed house number. You always type it yourself.
