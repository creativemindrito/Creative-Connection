# For your AI agent: how to find out

1. Find the device's exact brand and model.
2. Search for how this model can be woken over the network. Look for Wake-on-LAN, the brand's own protocol, network standby, a smart plug or the brand's cloud.
3. Check the settings on the device itself. Many devices only listen when a network wake-up setting is on.
4. Some apps don't let you look inside their code. Then look for open source programs or helper tools that already speak the device's language, use a research tool like REA, or make your own tool.
5. If the device needs a secret code, pair it once with such a program. Let your script read the code at the moment it runs, but never copy it into a script, a log or a chat.
6. Follow "Step by step: add a new device".
Tip: Some devices are hard. Take it step by step, and never guess with secret codes or the router.
