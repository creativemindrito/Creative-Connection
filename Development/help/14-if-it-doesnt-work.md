# If it doesn't work

1. Not found: the device didn't answer. Is it fully off instead of in rest mode? Is it on the same network?
2. Not found while the device is in rest mode: your firewall may be blocking the answer. Check the firewall settings for PowerShell.
3. Sent, but nothing happens: check the device's network wake-up setting, and wait about 30 seconds.
4. Failed: run the dry run in PowerShell and read the message.
5. The house number is red: the device got a new address. Reserve it in your router again. Read "Give your device a house number".
Tip: The log (the book at the top right) shows every time a button ran and what happened.
